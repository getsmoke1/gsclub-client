# Backlink Site Vetting SOP — GetSmoke.com

**Назначение:** Инструкция для агента, который отбирает сайты для размещения платных editorial бэклинков.

---

## 1. КОНТЕКСТ

**Клиент:** GetSmoke.com — интернет-магазин одноразовых вейпов (США)
**Цель бэклинков:** Поднять позиции в Google по запросам связанным с Geek Bar (основной бренд)
**Страницы назначения (ТОЛЬКО эти, не менять):**
- `https://getsmoke.com/brands/geek-bar`
- `https://getsmoke.com/models/geek-bar-pulse-2-25000-puffs`
- `https://getsmoke.com/models/geek-bar-pulse-x2-50000-puffs`

## 2. ОБЯЗАТЕЛЬНЫЕ ТРЕБОВАНИЯ (все должны выполняться)

### 2.1 Метрики домена
- **DR (Domain Rating) по Ahrefs:** минимум 35+
  - Исключение: локальные US новостные сайты — от 25+
- **Трафик:** минимум 500 уников/мес (проверять через SimilarWeb или Ahrefs)
- **Язык:** английский
- **Аудитория:** США (основной трафик должен идти из US)
- **Возраст домена:** минимум 2 года (проверить через Whois)

### 2.2 Тип контента
- Сайт публикует **редакционные статьи** (editorial) — не UGC, не форумы
- Статья размещается без пометок "Sponsored", "Advertorial", "Paid Post"
- У статьи будет URL на самом домене (не поддомен типа `medium.com/@site`)
- Статья остаётся на сайте **постоянно** (не удаляется через 6-12 мес)

### 2.3 Ссылки
- Минимум **2 dofollow** ссылки в статье
- Ссылки с **anchor text** (кликабельная фраза), не raw URL
- Ссылки ведут на коммерческие страницы getsmoke.com (бренд или модель)

## 5. КАК ПРОВЕРЯТЬ (пошаговый процесс)

### Шаг 1 — Базовая проверка (2 мин/сайт)
1. Открыть сайт вручную — выглядит ли как реальное СМИ?
2. Проверить наличие редакции / авторов с именами
3. Убедиться что контент разнообразный (не только оплаченные статьи)

### Шаг 2 — Метрики (Ahrefs / Moz / SimilarWeb)
1. Проверить DR через Ahrefs или Moz → должен быть 35+
2. Проверить трафик через SimilarWeb → должен быть 500+/мес
3. Проверить страну трафика → должен быть USA primary
4. Проверить Whois → домен должен быть 2+ лет

### Шаг 3 — Проверка на link farm
1. В Ahrefs открыть "Outgoing links" → если сотни ссылок на gambling/pharma/adult — отклонить
2. Поискать в Google: `site:домен.com "sponsored" OR "advertorial"` → если много результатов — осторожно
3. Поискать: `домен.com "guest post" "write for us"` → если открытый прайс — отклонить

### Шаг 4 — Проверка индексации
1. В Google ввести `site:домен.com` — должны быть результаты (сайт проиндексирован)
2. Проверить что последние статьи индексируются (не старше 6 мес)

### Шаг 5 — Финальное решение
Заполнить таблицу:

| Поле | Значение |
|---|---|
| Сайт | домен.com |
| DR | число |
| Трафик мес | число |

| Возраст домена | лет |
| Тип сайта | editorial / UGC / news / ... |
| Ниша | lifestyle / tech / ... |
| Editorial (без sponsored) | да / нет |
| dofollow ссылки | да / нет |
| Цена | $XX |

## 5.5 ПРАВИЛО: СБОР ЦЕНЫ ДО ОТПРАВКИ СТАТЕЙ

**Обязательный шаг перед отправкой любой статьи:**

1. Собрать офферы на один и тот же сайт от ВСЕХ продавцов которые его предлагали
2. Сравнить цены — выбрать минимальную
3. Только после этого отправлять статью выбранному продавцу

**Причина:** Один и тот же сайт может предлагаться несколькими продавцами по разным ценам. Отправка статьи = фактическое подтверждение сделки.
